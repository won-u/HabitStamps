## v1 MVP vs v2 이후

| 구분 | 기능 |
|---|---|
| **v1 (MVP) — ✅ 구현 완료** | 습관 생성/수정/삭제(이름·아이콘·컬러·그룹·반복주기), 그룹(카테고리)별 분류/생성, 반복주기 4종(매일/특정 요일/주 n회/월 n회), 오늘 화면 체크인/해제 + 헤더 날짜 클릭으로 임의 날짜 이동, 스트릭 계산(현재/최장 + 각 스트릭의 날짜 범위, 신기록 시 RECORD 배지), 캘린더 뷰(월간 도트+날짜별 상세, 스와이프 월 이동, **헤더 탭으로 특정 년/월 바로 이동**, **현재 월 기준 활성 습관별 체크인 카운트 목록**), 습관 상세 화면(연결형 스탬프 월간 캘린더, 탭-이동 후 탭-토글, **Statistic 타일 4개(이번주/이번달/올해/전체)**, 오늘로 이동 FAB), 통계 탭(요약 세그먼트: 앱 전체 카운트 타일 + 습관별 완료율·스트릭 / Weekly·Monthly·Yearly 세그먼트: 그룹별 도트 표·미니 캘린더 모자이크·GitHub식 히트맵, 각각 스와이프 이동 + 오늘로 이동 FAB, Monthly·Yearly는 습관별 체크인 카운트 표시), **습관 보관(archive)/복구 — 습관 수정 화면의 "보관하기" 버튼 + 설정 > 관리 > 보관된 습관 화면에서 복구**, 다크/라이트/시스템 테마, 동기화 2가지: **로컬 백엔드 push/pull(REST, 설정 > 동기화 > REST 백엔드에서 서버 URL/토큰 입력 후 수동 동기화)** 및 **Supabase(Postgres+Auth+RLS 무료 티어, 설정 > 동기화 > Supabase에서 프로젝트 URL/anon key 입력 + Google 로그인 후 동기화, 크로스플랫폼)** — 상세는 [architecture.md](./architecture.md) §5. Supabase는 스키마/RLS/충돌 해소 로직 검증에 이어 2026-08-11 실제 프로젝트 연동(로그인 왕복)까지 완료 |
| **v1 범위였으나 아직 미구현** | 체크인 시 텍스트 메모(모델·DB 필드는 있으나 입력 UI 없음), Journal(메모 모아보기 — 현재는 Report 화면으로 대체), 로컬 알림/리마인더(모델·`expo-notifications` 의존성은 있으나 스케줄링 미연결), 데이터 백업/복원(JSON export/import), 습관 순서 변경(드래그 정렬), 온보딩 플로우, 체크인 애니메이션의 컨페티 연출(scale-spring 체크마크만 구현, 파티클 미구현) |
| **v1.5 — 이번 반복에서 추가(원래 계획엔 없던 개선)** | 습관 등록 폼의 DayStamps식 컬러 박스 이름 입력 + 확장 컬러 그리드, 아이콘 프리셋에 데님/데님자켓 추가, Noto Sans KR 웹폰트 적용 및 색 톤 정제, 오늘 화면 카테고리별 접기/펼치기 그룹 섹션 |
| **v2 이후** | 체크인 시 사진 첨부, 습관 간 상관관계 분석, 홈스크린 위젯(iOS WidgetKit/Android 위젯 — 네이티브 확장 필요), AI 습관 추천, 실사용자 인증(계정 시스템)을 포함한 프로덕션 동기화, Web(Next.js) 클라이언트, Apple Watch/visionOS, 스마트 리마인더, 소셜 공유 |

**우선순위 원칙**: v1은 "만들기 → 체크하기 → 확인하기" 핵심 루프의 완성도에 집중하고, 화려한 시각화보다 통계 계산의 신뢰도를 우선한다.

**참고**: 반복주기가 "월 n회"인 습관은 통계/진행률 계산 기준이 주(week)가 아니라 해당 월(month)로 바뀐다(`apps/mobile/src/features/today/use-today.ts`의 `isMonthlyFrequency`).

## 핵심 사용자 플로우 (현재 구현 기준)

```
[첫 습관 생성]
  오늘 화면 빈 상태 → + FAB → 이름(컬러 박스 입력) → 아이콘 → 컬러
  → 그룹 선택/새 그룹 생성 → 반복주기(매일/특정요일/주n회/월n회) → 저장
       │
       ▼
[매일 체크인] (핵심 반복 루프)
  오늘 화면 → 습관 카드 체크 원 탭 → scale-spring 체크 애니메이션 → 카드가
  습관 컬러 → 회색으로 전환(완료 피드백) → 상단 날짜/그룹별 진행률 갱신
       │
       ▼
[과거·미래 날짜 확인/체크]
  헤더 날짜 클릭 → 날짜 선택 모달(스와이프로 월 이동, 미래 날짜 비활성) → 이동
  또는 10일 스트립에서 날짜 직접 탭
       │
       ▼
[습관 상세 확인]
  카드 탭 → 연결형 스탬프 월간 캘린더 → 날짜 탭(1차: 이동, 동일 날짜 재탭: 체크 토글)
  → Statistic 타일(이번주/이번달/올해/전체) → 현재/최장 스트릭 카드(날짜 범위, RECORD 배지)
  → 오늘로 이동 FAB(다른 달 조회 중일 때만 노출)
       │
       ▼
[통계 확인] (주 단위 방문)
  요약(앱 전체 카운트 타일+습관별 완료율·스트릭) / Weekly(요일별 도트) /
  Monthly(습관별 미니 캘린더+카운트) / Yearly(히트맵+카운트) 세그먼트 전환,
  Weekly·Monthly·Yearly는 좌우 스와이프로 기간 이동 + 오늘로 이동 FAB
       │
       ▼
[동기화 검증] (설정 > 동기화, 선택적)
  REST 백엔드 URL/토큰 입력 또는 Supabase 프로젝트 URL/anon key 입력 + Google 로그인
  → 지금 동기화 → push/pull 결과·충돌 건수 확인
```

**엣지 케이스**: 습관이 하나도 없을 때(빈 상태 CTA), 미래 날짜는 캘린더/날짜 선택 모달에서 탭 비활성화(사후 조작 방지), 과거 날짜 체크인은 습관 상세 화면의 월간 캘린더에서만 토글 가능.

**아직 없는 플로우**: 온보딩 슬라이드, 리마인더 알림, 체크인 메모 입력, 데이터 백업/복원 — [v1 범위였으나 아직 미구현] 참고.
