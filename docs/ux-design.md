# UI/UX 설계

> 기능 범위는 [features.md](./features.md), 아키텍처는 [architecture.md](./architecture.md), 진행 상황은 [roadmap.md](./roadmap.md) 참고
> 이 문서는 **DayStamps 레퍼런스 스크린샷 분석 후 실제 구현된 디자인**을 기술한다. 최초 계획 단계의 범용 디자인 초안은 이후 레퍼런스 이미지 비교를 거치며 아래 내용으로 대체되었다.

## 1. 디자인 컨셉

- **한 줄 컨셉**: "캘린더에 쌓이는 색" — 습관 하나하나가 자기 색을 갖고, 체크인이 쌓일수록 캘린더/리포트에 그 색이 번져 보이는 것 자체가 성취의 시각적 증거가 되게 한다.
- **시그니처 인터랙션(체크인)**: 오늘 화면 카드의 체크 원 탭 → scale-spring 애니메이션(1.0 → 1.2 → 1.0) → 카드 배경이 **습관 컬러 → 중립 회색(`backgroundElement`)** 으로 전환되고 체크마크가 채워짐. 이 색-회색 전환 자체가 "완료" 피드백이며 별도의 취소선/배너/컨페티는 아직 없다(→ [features.md](./features.md) 미구현 목록). 재탭(해제)은 단순히 원래 색으로 되돌아가며 확인 다이얼로그 없음(되돌리기 쉬움 원칙).
- **컬러 철학**: 배경/구조는 다크 기준 무채색(`#15171A` 계열), 습관별로만 12색 팔레트 컬러를 카드 전체 배경(full-bleed)에 입혀 리스트 자체가 다채로워 보이게 한다 — 배경/구조가 아니라 "카드 전체"가 색을 갖는 것이 DayStamps 대비 핵심 차용 포인트.
- **접근성 라벨**: 체크 원에 `"{습관명}, {완료/미완료}, 두 번 탭하여 완료 표시"` 형태의 명시적 accessibilityLabel 부여(색만으로 상태를 전달하지 않음) — `habit-card.tsx` 구현.

## 2. 정보 구조 / 네비게이션 (실제 구현)

하단 탭 4개: `[오늘] [캘린더] [통계] [설정]`

- **오늘**(`(tabs)/index.tsx`): 기본 진입 화면.
- **캘린더**(`(tabs)/calendar.tsx`): 전체 습관 통합 월간 뷰.
- **통계**(`(tabs)/stats.tsx`): 이번주/이번달/올해/전체 요약 타일 + 습관별 완료율·스트릭 리스트. **이번 반복에서 만든 Weekly/Monthly/Yearly 리포트 화면(§2-6)은 탭이 아니라 오늘 화면 헤더의 막대그래프 아이콘에서 스택 push로 진입**한다 — 통계 탭과 리포트 화면이 별개 경로로 남아 있는 점은 알려진 정리 대상(roadmap 참고).
- **설정**(`(tabs)/settings.tsx`): 외관(라이트/다크/시스템) + Developer 동기화 섹션.

습관 생성/수정/상세는 스택 push(`habit/new`, `habit/[id]/edit`, `habit/[id]/index`)로 처리한다.

## 3. 화면별 실제 구현

### 3-1. 오늘 화면(홈) — `(tabs)/index.tsx`

- 헤더: `{M월 d일} {WED 등 영문 요일 배지}` — **날짜 텍스트를 탭하면 날짜 선택 모달(§3-6)이 열려 10일 스트립 범위 밖의 날짜로도 이동 가능**. 우측에 리포트 진입 아이콘(막대그래프) + 습관 추가 아이콘.
- 10일 날짜 스트립: 오늘 기준 이전 9일~오늘, 가로 스크롤 없이 고정 폭 배치, 선택된 날짜만 테두리 강조.
- 습관 리스트는 **카테고리(그룹)별로 접기/펼치기 가능한 섹션**으로 분리(그룹 없는 습관은 "기본" 섹션). 섹션 헤더에 그룹별 진행률(`완료/전체`) 배지.
- 습관 카드(`HabitCard`, §1 참고): 아이콘+이름, 서브텍스트(마지막 체크인 상대 시각), 기간 진행률 배지(`count/target` — 주간 또는 "월 n회" 습관은 월간 기준), 카드 전체가 `Link`로 습관 상세로 이동.
- 하단 우측 `+` FAB → 습관 추가.

### 3-2. 습관 추가/수정 — `habit/new.tsx`, `habit/[id]/edit.tsx` (공용 `habit-form.tsx`)

DayStamps의 "New Activity" 폼을 참조해 구현:

- **이름 입력**: 입력창 배경 자체가 현재 선택된 습관 컬러로 채워짐(플레이스홀더 "예: 물 마시기") — 저장 전부터 완성될 카드의 색을 미리 보여주는 것이 목적.
- **아이콘**: 프리셋 그리드(물방울·러닝·책·명상·샐러드 등 기존 세트 + **데님자켓🧥·청바지👖 추가**).
- **컬러**: 12색 원형 스와치 그리드, 선택된 색에 체크마크 표시.
- **그룹**: 기존 그룹 칩 목록(예: 기본/Exercise) + `+ 새 그룹` 칩으로 인라인 그룹 생성. 그룹은 카테고리 리포지토리에 실시간 반영되어 즉시 칩으로 나타남.
- **반복 주기**: 4개 세그먼트 `매일 | 특정 요일 | 주 n회 | 월 n회`.
  - 특정 요일: 요일 칩 다중 선택.
  - 주 n회 / 월 n회: 각각 `- {n}회 +` 스테퍼(월 n회는 1~31회 범위).
- 하단 `저장` 버튼(이름 미입력 시 비활성).
- 수정 화면은 삭제 액션 포함(확인 다이얼로그 후 삭제, 삭제 시 오늘 탭으로 replace 이동).

### 3-3. 습관 상세 — `habit/[id]/index.tsx`

- **연결형 스탬프 월간 캘린더**: 연속 체크된 날짜는 셀 사이 여백/모서리 둥글기가 사라지며 하나의 알약(pill) 모양으로 합쳐짐 — DayStamps 시그니처 비주얼.
- **탭 인터랙션(2단계)**: 날짜를 처음 탭하면 해당 날짜가 "선택"(테두리 강조)만 되고, **같은 날짜를 한 번 더 탭해야 체크인이 토글**된다. 실수로 캘린더를 훑어보다 엉뚱한 날짜가 체크되는 것을 방지하기 위한 의도적 2단계 제스처. 미래 날짜는 탭 비활성.
- 월 이동: 좌우 화살표 버튼 + `useSwipeNavigation` 훅으로 좌우 스와이프 동시 지원.
- 이번 달 체크인 횟수 텍스트, 현재/최장 스트릭 카드 2개.
- 다른 달을 보고 있을 때만 우하단 "오늘로 이동" FAB 노출.

### 3-4. 캘린더 탭 — `(tabs)/calendar.tsx`

- 전체 습관을 한 화면에서 보는 월간 그리드(7×N), 각 날짜 셀에 그날 체크인이 있는 습관들의 컬러 도트(최대 4개)를 표시.
- 날짜 셀 탭 → 하단에 해당 날짜의 습관별 체크인 상세(아이콘/이름/메모) 표시.
- 월 이동 버튼 + 스와이프, **헤더의 "yyyy년 M월" 텍스트를 탭하면 년/월 선택 모달(`year-month-picker-modal.tsx`)이 열려 몇 달치를 스와이프/버튼으로 넘기지 않고 원하는 년/월로 바로 점프** 가능.
- 그리드 아래에 **현재 표시 중인 월 기준, 활성(비보관) 습관별 체크인 카운트 목록**(아이콘/이름 + "N회")을 표시 — 습관이 보관되면 이 목록·그리드 도트 모두에서 자동으로 빠진다(§3-8 참고).
- 다른 달 조회 중엔 "오늘로 이동" FAB.

### 3-5. 리포트 화면 — `report.tsx` (스택 push, 오늘 화면 헤더 아이콘에서 진입)

세그먼트 컨트롤 `Weekly | Monthly | Yearly`, 그룹(카테고리)별로 묶어서 표시, 각 모드는 독립된 기간 앵커(주/월/년)를 가지며 좌우 스와이프로 이동:

- **Weekly**: 그룹별 테이블 — 습관 행 × 요일(일~토) 열, 체크된 날은 습관 컬러 도트.
- **Monthly**: 습관별 미니 월간 캘린더 모자이크(2열 그리드), 카드 헤더에 **해당 월 체크인 카운트("N회")** 표시.
- **Yearly**: 습관별 GitHub 컨트리뷰션 그래프 스타일 히트맵(주 단위 컬럼 × 요일 단위 로우, 가로 스크롤), 카드 헤더에 **해당 연도 체크인 카운트("N회")** 표시.

세 모드 모두 현재 보고 있는 기간이 "오늘이 포함된 기간"이 아닐 때만 우하단 "오늘로 이동" FAB 노출.

### 3-6. 날짜 선택 모달 — `date-picker-modal.tsx`

오늘 화면 헤더 날짜 텍스트를 탭하면 뜨는 모달. 월 단위 그리드, 스와이프로 월 이동, 오늘 이후 날짜는 비활성화, 날짜 선택 시 오늘 화면의 조회 날짜(`viewedDate`)가 즉시 바뀌고 모달이 닫힌다.

### 3-7. 설정 화면 — `(tabs)/settings.tsx`

- 외관: 시스템/라이트/다크 세그먼트.
- 관리: "보관된 습관 관리" 링크 → §3-8의 아카이브 화면으로 이동.
- Developer: Sync Server URL, Device Token 입력 + "지금 동기화" 버튼, 결과(push/pull 건수, 충돌 건수) 텍스트 표시.

### 3-8. 습관 보관/복구 — 습관 수정 폼 + `archive.tsx`

- 습관 상세 → 수정 화면(`habit/[id]/edit.tsx`)에 삭제와 별개로 **"보관하기"** 버튼이 있다. 보관은 소프트 삭제가 아니라 `isArchived: true` 플래그만 세우는 가역적 동작이라 확인 다이얼로그 없이 즉시 실행된다.
- 보관된 습관은 오늘/캘린더/리포트/통계 화면의 기본 조회(`observe()`)에서 자동으로 제외된다 — 화면마다 별도 필터링 코드를 추가할 필요 없이 `HabitRepository.list/observe({ includeArchived })`의 기본값이 "보관 제외"이기 때문(§3-4의 캘린더 습관별 카운트도 동일하게 적용).
- 설정 화면의 "관리 > 보관된 습관 관리" → `archive.tsx`에서 보관된 습관만 모아보고, 각 행의 **"복구"** 버튼으로 `isArchived: false`로 되돌리면 즉시 오늘 화면 등에 다시 나타난다.

## 4. 비주얼 디자인

**타이포그래피**: Noto Sans KR(`@expo-google-fonts/noto-sans-kr`)을 `useFonts`로 로드. RN이 커스텀 TTF의 굵기를 합성하지 못하므로 굵기별로 **별도 `fontFamily` 값**(`NotoSansKR_400Regular` / `500Medium` / `600SemiBold` / `700Bold`)을 직접 지정 — `fontWeight` 숫자 지정 방식은 쓰지 않는다.

**컬러 토큰**(`constants/theme.ts`):

| 토큰 | 라이트 | 다크 |
|---|---|---|
| background | (theme.ts 참조) | `#15171A` 계열 |
| backgroundElement | — | 카드/서피스 배경 |
| backgroundSelected | `#E7E6E9` | `#272A33` |

습관 컬러 팔레트는 12색 원형 스와치(폼의 §3-2 참고), 다크모드에서도 동일 hue 유지.

## 5. 마이크로 인터랙션/제스처

| 인터랙션 | 구현 |
|---|---|
| 체크인 토글 애니메이션 | `react-native-reanimated`(`withSequence(withSpring)` scale) + `expo-haptics` light impact |
| 월/주/연 스와이프 이동 | 자체 `useSwipeNavigation` 훅(`hooks/use-swipe-navigation.ts`) — 순수 RN `PanResponder` 기반. `react-native-gesture-handler`의 `GestureDetector`/`GestureHandlerRootView` 설정이 필요 없어 채택. `dx`가 `dy*1.5`보다 크고 ±50px 이상일 때만 스와이프로 판정 |
| `<Link asChild>` + 배열 스타일 | `expo-router`의 Slot 구현은 자식의 `style`이 배열이면 런타임 에러를 던진다. FAB/카드처럼 `Link asChild` 안의 `Pressable`에 배열 스타일을 줄 때는 반드시 `StyleSheet.flatten([...])`로 감싼다(`habit-card.tsx` 참고) |

## 6. 접근성

- 색상은 항상 아이콘/이모지와 병행 표시(색맹 대응).
- 체크 원에 명시적 접근성 라벨 부여(§1 참고) — 취소선/컬러 변화만으로 상태를 전달하지 않음.
- 시스템 다이나믹 타입, "동작 줄이기(Reduce Motion)" 대응, WCAG AA 명도 대비는 **아직 별도 검증하지 않음** — v1.5 이후 점검 대상.

## 7. 알려진 갭 (다음에 다듬을 것)

- 통계 탭(§2)과 리포트 화면(§3-5)이 별도 경로로 분리되어 있어 발견성이 낮다 — 통계 탭에서도 리포트로 진입하는 도선을 추가하는 편이 자연스럽다.
- 체크인 완료 시 컨페티/축하 배너 등 초기 계획에 있던 연출은 아직 없다(scale-spring 전환만 구현).
- 습관 카드에서 롱프레스 메뉴(메모/스킵/수정/삭제)는 미구현 — 현재 수정/삭제는 상세 화면 진입 후에만 가능.
